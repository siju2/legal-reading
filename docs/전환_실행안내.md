# 판결읽기 전환 안내

기존 Spring Boot `Project`를 생활법률 판결 아카이브로 전환했습니다.

- 실행 주소: http://localhost:8080/
- STS의 프로젝트 이름과 실행 클래스는 기존 `Project` / `ProjectApplication` 그대로입니다.
- 파일이 보이지 않으면 STS에서 Project를 선택하고 F5로 새로고침하세요.
- 일반 회원은 기존 계정으로 로그인하거나 새로 가입할 수 있습니다.
- 관리자 계정 정보는 Project 폴더의 `data/legal-admin-initial.txt`에 저장합니다. 저장소에는 포함하지 않습니다.
- 실행 중인 서버를 종료한 후 STS에서 Run As → Spring Boot App으로 다시 실행할 수 있습니다.

## 구현된 기능

상황 검색·생활 분야·실제/가상 구분·판결 해설·원문 링크·두 사례 비교·용어 사전·공식 도움 경로·회원 보관함·개인 메모·관리자 등록/편집/공개·변경 이력을 제공합니다.

초기 실제 판결은 공식 출처를 확인한 3건이며 가상 학습 자료는 3건입니다. 해설은 전문가 검수 전 표시를 유지합니다. 자동 AI 상담이나 전국 모든 판결의 자동 수집을 구현한 것은 아닙니다.

기존 회원·로스트미디어 DB 테이블·업로드 파일은 보존했습니다. 전환 전 코드·설정·문서는 복구 ZIP으로 백업했습니다. 기존 로스트미디어 SRS와 일정표는 새 서비스의 명세가 아닙니다.

새 GitHub 저장소: https://github.com/siju2/legal-reading (비공개). 새 주제의 SRS·발표 자료는 별도 개정이 필요합니다.
