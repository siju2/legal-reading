# 로컬 DB 및 더미 데이터

Java 17 이상, Maven, 실행 중인 로컬 MySQL이 필요합니다. 이 도구는 명시적으로 실행할 때만 데이터를 추가하며 애플리케이션 시작 시 실행되지 않습니다.

## DB 준비

1. MySQL에 UTF-8 데이터베이스 `project`와 해당 DB를 사용할 로컬 계정을 준비합니다.
2. `DB_USERNAME`, `DB_PASSWORD` 환경 변수 또는 Git에서 제외된 `src/main/resources/application-local.properties`에 접속 정보를 설정합니다. Spring 표준 `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD` 환경 변수도 지원합니다.
3. 애플리케이션을 한 번 실행해 JPA 테이블을 생성합니다. 빈 판례 테이블에는 실제 판결 기반 자료 3건과 가상 사례 3건이 자동 생성됩니다.
4. 프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
./scripts/seed-demo.ps1
```

스크립트는 `localhost` 또는 `127.0.0.1`의 MySQL만 허용합니다. 별도 원격 DB용 도구가 아닙니다. Maven이 프로젝트 의존성을 내려받을 수 있어야 합니다. 애플리케이션 스키마를 변경한 경우 먼저 애플리케이션을 실행해 반영하세요.

## 생성되는 데이터

| 종류 | 수량 |
| --- | ---: |
| 일반 테스트 계정 `demo_legal` | 1 |
| 노트 | 105 |
| 타임라인 | 1,015 |
| 체크리스트 | 820 |
| 상담 후 기록 | 305 |
| 북마크 | 최대 4 |
| 과거 AI 사용 이력 | 3 |
| 결제 샘플 | 2 |

주거·일자리·돈/거래·온라인 생활·일상 사고의 각 분야에 노트 21개를 생성합니다. 다양한 날짜와 완료 상태로 검색·페이징·진행률·PDF·JSON 백업을 확인할 수 있습니다. 연결 가능한 공개 자료가 있을 때만 참고 사례와 북마크를 연결합니다.

새 계정의 무작위 비밀번호는 `data/demo-login.txt`에만 저장하며 DB에는 BCrypt 해시를 저장합니다. `data/`는 Git에서 제외됩니다. 계정에는 관리자 권한을 부여하지 않습니다. 기존 테스트 계정이 있으면 비밀번호와 기본 데이터를 변경하지 않고, 확장 노트는 계정과 고유 제목으로 중복 생성을 방지합니다. 기존 더미 항목을 삭제하거나 제목을 바꾼 경우 재실행 결과가 처음과 다를 수 있습니다.

각 Java 도구는 개별 트랜잭션으로 실행됩니다. 기본 데이터 생성 후 확장 단계가 실패하면 기본 데이터는 유지됩니다. 오류 원인을 수정하고 다시 실행할 수 있습니다. 기존 사용자 데이터는 삭제하거나 수정하지 않습니다.

모든 상담·사건 기록은 가상 학습 자료입니다. AI 사용 이력은 과거 날짜의 샘플일 뿐 실제 API를 호출하지 않습니다. 결제는 가상 상점의 `READY`·`CANCELLED` 상태이며 실제 결제나 유료 이용 권한을 생성하지 않습니다.

DB 접속 비밀번호, 테스트 로그인 파일, 실제 DB 덤프는 커밋하지 마세요. 이 스크립트는 DB 백업을 대신하지 않습니다.
