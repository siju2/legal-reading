# 판결읽기 추가 기능과 API 설정

## 바로 사용하는 기능

- 상황별 질문: http://localhost:8080/situation
- 본문 밑줄 용어를 눌러 쉬운 설명 확인
- 나의 사건 노트: http://localhost:8080/notebooks (로그인 필요)
- 노트별 날짜순 타임라인, 자료 체크리스트와 진행률
- 참고 사례의 체크리스트로 새 노트 만들기

개인 노트는 다른 회원·관리자에게 표시하지 않으며 외부 API로 전송하지 않습니다. 노트와 체크리스트는 자료 정리를 돕고, 법률상 결론·기한을 계산하지 않습니다.

## 공식 법률 API

화면: http://localhost:8080/law-search

법제처 판례·법령 검색과 판례 본문을 조회하는 연동 코드를 적용했습니다. 아직 OC 인증값이 없어 현재는 실시간 조회 대기 상태입니다. 인증값이 없을 때는 공식 사이트로 이동해 검색할 수 있습니다.

1. https://open.law.go.kr/ 에서 공동활용 API 신청·인증값·이용 승인을 확인합니다.
2. Spring Project 안의 `data/law-api.properties` 파일을 메모장 등으로 엽니다.
3. `legal.law-api.oc=` 뒤에 발급받은 인증값을 입력하고 UTF-8로 저장합니다.
4. 사이트에서 다시 조회하면 읽으므로 서버 재시작은 필요하지 않습니다.

설정 여부는 인증값 존재만 뜻합니다. 실제 API 인증·이용 승인·연결 성공은 조회 결과로 확인해야 합니다. 오류 안내와 정상 결과 0건은 구분해서 표시합니다. 인증값을 채팅으로 보낼 필요는 없습니다.

서버는 고정 법제처 HTTPS 주소만 호출하고 원격 HTML을 실행하지 않습니다. data 폴더는 Git에서 제외되며 인증값은 화면·상태 API·오류 메시지에 표시하지 않습니다.
